# Foam Bubble Parties Website Guidelines

## Mission

Build the highest-quality foam party website in Ohio.

The website should feel like a premium children's entertainment company comparable to Apple, Disney, Tesla, Airbnb, or Stripe in terms of polish, simplicity, animations, and user experience.

Every change should increase trust, excitement, and conversion rates.

## Primary Goal

The goal is to maximize bookings.

Every design decision should answer:

> Does this increase the likelihood that a parent books a party?

## Business Context

The company launches in Spring 2027.

This website exists to generate bookings and build trust before launch.

### Services

**Primary service:** Foam Parties

**Future services:**

- Schools
- Daycares
- Churches
- Summer Camps
- Festivals
- Community Events

The site should make foam parties the clear primary offering while remaining flexible enough to add future event-service pages without a redesign. Always think long-term.

## Target Customers

**Primary:** Parents ages 25–45 booking birthday parties.

**Secondary:** Schools, daycares, churches, summer camps, and community events.

## Brand Personality

- Fun
- Premium
- Modern
- Clean
- Exciting
- Professional
- Family friendly

Never childish, cheap, or cluttered.

## Design Requirements

The design should feel like a luxury event company.

- Large typography
- Beautiful spacing and generous whitespace
- High-end, tasteful animations
- Professional photography
- Rounded cards and appropriate glass effects
- Modern gradients
- Excellent mobile experience
- Teal as the primary color, purple as secondary, and pink as an accent
- Generous use of white; dark sections may provide contrast
- Avoid rainbow overload

## Typography

- Large headings
- Easy-to-read body copy
- Generous spacing
- Mobile-first readability

## Booking Experience

Booking should be effortless.

- Minimize clicks
- Make pricing clear
- Use prominent calls to action
- Offer easy contact options
- Keep trust signals visible

## Performance

Performance is critical. Aim for Lighthouse 95+.

- Fast loading
- Lazy-load images
- Compress assets
- Use responsive images
- Never sacrifice speed unnecessarily

## Accessibility

Follow WCAG best practices.

- Maintain proper contrast
- Support keyboard navigation
- Use semantic HTML
- Provide descriptive alt text
- Use ARIA where appropriate

## SEO

Every page should include:

- A unique title
- A meta description
- Open Graph tags
- Schema markup when appropriate
- Descriptive URLs
- Fast loading

## Animations

Motion should feel smooth and professional.

- Use tasteful motion that enhances the experience
- Avoid excessive bouncing or distracting effects

## Code Style

- Write readable code
- Prefer simple solutions
- Avoid unnecessary libraries
- Comment only when needed
- Keep components small
- Organize folders logically
- Avoid duplication

## Before Making Changes

1. Read the project and understand its architecture.
2. Preserve existing functionality and design language.
3. Explain the implementation plan before major structural changes.
4. Ask if major rewrites are necessary.
5. Improve quality incrementally.

Never introduce breaking changes or remove features unless requested. Optimize for maintainability.

## Mobile First

The mobile experience is the highest priority. Every page should look exceptional on phones before desktop.

## Images

- Use placeholders if necessary
- Never use low-quality graphics
- Prefer full-width hero images
- Optimize every image

## Future Features

Design so these can be added later without major rewrites:

- Online booking
- Deposits
- Customer portal
- Gallery
- Blog
- Referral program
- Gift cards
- Merchandise
- Customer reviews
- Video testimonials
- Franchise locations

## Quality Standard

Every page should feel like it belongs in the top 1% of entertainment company websites.

When choosing between faster to build and higher quality, choose higher quality.
